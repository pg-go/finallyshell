## 窗口布局

主窗口和 FinalShell 的布局一样，只是会话标签是竖向的：

- 左上：当前会话的服务器监控。
- 左下：竖向会话列表。
- 右上：终端。
- 右下：“文件”“传输”“隧道”“进程”四页。

## 会话和标签

窗口左下是竖向的会话列表，标题是“会话 (N)”。每个会话有一个状态点：绿色是已连接，黄色是连接中，红色是失败。列表可以滚动，会话可以拖动排序。会话的右键菜单有 “重新连接”“复制会话”“断开”“关闭”。

“+”按钮新开一个新标签页（见下面）。新标签页和会话一样可以切换、拖动、关闭，但标题里的数目不算新标签页。全部关掉后右边仍显示快速连接，在那里连接会新开一个标签页。

连接成功时记下时间，供快速连接的“最近连接”使用。主机的 `noMonitor` 为 `true` 时不轮询服务器状态，也就不开额外的 exec 通道（有些跳板机不允许）。

第一次连接一台主机时弹窗显示主机指纹，信任后记入配置目录里的 `finallyshell/known_hosts`。指纹变化的连接会被拒绝。

## 新标签页和快速连接

启动时打开一个新标签页。上面的“快速连接”列出所有没删除的主机（名称、主机、用户名）：

- 先是最近连接过的（最多 30 个），最后连接的在最上面。
- 下面是其他主机，最后添加的在最上面。新建、复制、导入时记下添加时间（`createdAt`）。没有添加时间的旧主机排在最后，按保存的顺序。

两部分都有时上面分别标着“最近连接”“其他连接”。所以刚添加的主机不用先连接一次，马上就出现在这里。

- 点一下或按回车就在这个标签页里连接，同一行变成会话。
- 搜索框边输入边过滤，按名称、地址、用户名、备注匹配，顺序和不搜索时一样。上下方向键选择，跳过“最近连接”“其他连接”这两行。
- “清空”清掉最近连接记录。不删主机，它们都还列在“其他连接”里。
- “连接管理器”按钮打开连接管理器。在新标签页选中时从连接管理器连接，也连在这个标签页里。
- 一个主机都没有时显示“新建连接”按钮，下面是“连接管理器”按钮，新用户还没添加主机也能从别的客户端导入连接（见下文）。

## 连接管理器

连接管理器在 macOS 上用 Cmd+O 打开，其他系统用 Ctrl+Shift+O（可以在“快捷键”页改）。它是单独的窗口，标题是“连接管理器”。和 FinalShell 一样是文件夹和连接的树，列是名称、主机、端口、用户名、备注（备注只显示第一行）。点列头排序，拖列头边缘改宽度。

主机列表存在 `<用户配置目录>/finallyshell/hosts.json`。密码从不写进去，存在系统的凭据存储里（见[密码存在哪里](configuration.md#密码存在哪里)）。

工具栏：

- 新建连接。
- 新建文件夹：建在选中的文件夹里，选中的是连接就建在它所在的文件夹里。
- 全部折叠、全部展开。
- 导入：从别的客户端导入连接（见下面）。
- 显示已删除。
- 文件夹筛选：“全部”，或只看某个文件夹。
- 搜索框。

树的下面是“连接后关闭窗口”，默认勾选。它记在 `settings.json` 的 `keepManagerOpen` 里，没有这一项就是关闭。

搜索边输入边过滤，按名称、地址、用户名、备注匹配，每个词都要匹配，不分大小写。自动展开含有结果的文件夹并选中第一个结果，回车就连接它。清空搜索后恢复原来展开的文件夹。

双击连接或按回车：在主窗口打开会话（主窗口选中的是新标签页时就连在那个标签页里），把主窗口提到前面，勾选了“连接后关闭窗口”就关掉连接管理器。

连接的右键菜单：

- 连接。
- 编辑。
- 复制连接：副本的名称是“<名称> - 副本”。代理或跳板机设置、隧道、记住的密码和代理密码也一起复制，凭据存储里的也复制到新连接下。
- 重命名（F2）。
- 移动到文件夹。
- 复制主机地址：复制主机的地址。
- 删除（Delete 键）。

文件夹的右键菜单有新建连接、新建子文件夹、重命名、移动到文件夹、删除。删除文件夹前先问。里面的连接和子文件夹移到它的上一级（顶层的文件夹就移到顶层），提示里会写明移到哪里。

把连接或文件夹拖到文件夹那一行就移进去，拖到连接那一行就移到那个连接所在的文件夹，拖到空白处移到顶层。文件夹不能拖进自己或自己的子文件夹。

删除连接只是移到“已删除”（`deletedAt`）。勾选“显示已删除”后，已删除的连接灰色显示在原来的文件夹里，右键可以“恢复”或“彻底删除”（先问）。彻底删除都走 `deleteHostForever`，同时清掉为这个主机记住的密码和代理密码，内存里的和凭据存储里的都清掉。

删除（或彻底删除）别的连接正在用的跳板机时先问，提示里列出哪些连接会因此连不上。跳板机的下拉框本来就只列没删除的连接。

从连接管理器打开的连接编辑器是连接管理器的模态窗口（见 [子窗口](development.md#子窗口)）。保存后连接管理器里马上显示并选中这个连接。

## 导入连接

连接管理器工具栏的“导入”打开“导入连接”窗口，是连接管理器的模态窗口。顶上的“导入来源”选从哪里导入：下面的各个来源，每个一节。窗口打开时是这次启动以来最后选的来源（第一次是 FinalShell）。

选了来源就去它存放连接的地方找它的文件或目录（读文件在 goroutine 里，读完通过 `App.post` 显示）。找不到，或者这个来源没有固定的位置，就弹出选择文件或文件夹的对话框（显示隐藏文件和文件夹）。取消了就说明要选什么，并给出选择的按钮。读到之后，顶上显示它的路径（除了 Windows，主目录写成 `~`），旁边的“选择文件…”或“选择文件夹…”随时换一个。

窗口里列出读到的所有 SSH 连接（名称、主机、用户名、文件夹、说明），每行一个复选框，默认全选。“全选”“全不选”改变所有行，回车、双击或空格切换选中的一行。

- 和已有主机地址（不分大小写）、端口、用户名都相同的连接灰色显示“已存在：…”，不能勾选，不会导入。来源里两条相同的，只导入第一条。
- 读不了的文件或文件里的行（格式不对、太大、读取失败、没有主机地址）算失败。其他类型的连接（RDP、VNC 等）和在别的客户端里已删除的连接算跳过。两种都列在表格下面，带着文件名，或者文件名和行号（`文件:行`）。
- “说明”列写着连接的哪些设置没有导入，比如代理，或者导入后要选私钥文件，以及它要经过的跳板机。

点“导入 N 个”：按来源的文件夹结构放进同名文件夹。从顶层逐级按名称找，已有的就用，没有就新建，只建有连接导入的文件夹。没有文件夹的来源导入到顶层。然后关掉窗口，在连接管理器里展开这些文件夹、选中第一个导入的连接，连接管理器底部显示导入、跳过、失败各多少个，以及多少个要选私钥文件。

所有来源都一样：

- 添加时间（`createdAt`）记为导入的时间，所以导入的连接在快速连接里排在“其他连接”的前面。
- 别的客户端存的密码不导入：它们用自己的密钥加密，Finallyshell 不解密。第一次连接时会询问（默认记住，存进系统的密钥库）。带密码的服务器列表，密码存进系统的密钥库，和“记住密码”一样，不会写进 `hosts.json`。
- 来源写明的私钥文件就是导入后主机的私钥文件。存在别的客户端自己的密钥库里的私钥不导入：主机是“私钥”认证但没有私钥文件，“说明”列和导入结果会提示去选。

### 从 FinalShell 导入

FinalShell 把连接存在数据目录的 `conn` 文件夹里，Finallyshell 按顺序找数据目录：

- Windows：`%LOCALAPPDATA%\finalshell`、`%APPDATA%\finalshell`、`%ProgramFiles%\FinalShell`、`%ProgramFiles(x86)%\FinalShell`、`C:\finalshell`。FinalShell 装在别的目录、数据也在安装目录里时，要自己选。
- macOS：`~/Library/FinalShell`、`~/Library/Application Support/finalshell`。
- Linux：`~/.finalshell`、`~/.local/share/finalshell`。

可以选数据目录、它的 `conn` 文件夹，或者 FinalShell 导出的文件夹。

导入的字段：名称、主机、端口、用户名、备注（`description`）、文件夹、认证方法、是否启用 exec 通道（关掉的导入后关闭服务器监控）。添加时间不用 FinalShell 的 `create_time`。

- 密码不导入。FinalShell 把密码加密存在文件里，Finallyshell 不解密，也不读这个字段。
- 私钥认证的连接导入后是“私钥”认证但没有私钥文件。FinalShell 把私钥存在它自己的 `config.json` 里，连接只记着私钥的 ID；这个文件不读，要编辑连接选私钥文件。
- 代理（`proxy_id` 指向 FinalShell 自己的代理列表）、端口转发、终端编码、退格键设置都不导入（还不知道 FinalShell 存的值是什么格式）。用了代理的连接在“说明”列里注明。

FinalShell 的文件格式没有官方文档，导入按其他开源客户端（Hatoba、LiteShell、MeatShell、OpenFinalShell）的 FinalShell 导入代码整理，写在 `internal/importer/finalshell.go` 的注释里。解析尽量宽松：不认识的字段忽略，缺的字段用默认值（端口 22、密码认证），端口写成字符串也认。

### 从 Xshell 导入

Xshell 把每个会话存成一个文件 `<名称>.xsh`，放在它的 `Sessions` 文件夹里，子文件夹就是它的文件夹。在 Windows 上，Finallyshell 按顺序找这个文件夹：

- `文档\NetSarang Computer\<版本>\Xshell\Sessions`（Xshell 6 及以后），新版本优先，用户目录的“文档”和 OneDrive 的“文档”都找。
- `文档\NetSarang\Xshell\Sessions`（Xshell 5）。
- `%APPDATA%\NetSarang\Xshell\Sessions`（更早的版本）。

在 macOS 和 Linux 上，或者 Xshell 的会话存在别处（在它的选项里设置）时，要自己选。可以选 `Sessions` 文件夹、它所在的 `Xshell` 文件夹，或者任何里面有 `.xsh` 文件或 `.xts` 导出文件（Xshell 的“文件”→“导出”）的文件夹：导出文件直接读，不解压，里面的文件夹导入到它所在的文件夹下面。选择对话框只能选文件夹，所以要导入 `.xts` 文件，就选它所在的文件夹。

导入的字段：名称（文件名去掉 `.xsh`）、主机、端口、用户名、备注（会话的“说明”）、文件夹、认证方法。只导入 SSH 会话；Telnet、Rlogin、串口等会话跳过。

- 密码不导入。Xshell 把密码加密存在会话文件里，Finallyshell 不解密，也不读这个字段。
- 公钥认证的会话导入后是“私钥”认证但没有私钥文件：Xshell 把私钥存在它自己的密钥库里，会话只记着私钥的名字。要编辑连接选私钥文件（需要的话从 Xshell 的“用户密钥”导出成 OpenSSH 格式）。
- 代理（Xshell 自己代理列表里的名字）、端口转发、终端设置都不导入。用了代理的会话在“说明”列里注明。

Xshell 的会话文件没有官方文档，导入按用户公开的会话文件和其他读这种文件的工具整理，写在 `internal/importer/xshell.go` 的注释里。Xshell 6 及以后写的文件（UTF-16）和旧版本写的文件（ANSI 代码页，中文 Windows 上是 GBK）都能读。解析尽量宽松：不认识的段和字段忽略，没写协议算 SSH，没写端口算 22。

### 从 SecureCRT 导入

SecureCRT 在配置文件夹的 `Sessions` 文件夹里每个会话存一个 `.ini` 文件，它的每个文件夹是一个子文件夹。Finallyshell 在这里找配置文件夹：

- Windows：`%APPDATA%\VanDyke\Config`。
- macOS：`~/Library/Application Support/VanDyke/SecureCRT/Config`。
- Linux：`~/.vandyke/SecureCRT/Config`。

SecureCRT 可以把配置文件夹放到别处（Options › Global Options › General › Configuration Paths 里能看到在哪）。可以选配置文件夹、它的 `Sessions` 文件夹，或者里面的某个文件夹（导入它的会话，文件夹从它下面算起）。`Sessions` 顶层的 `Default.ini` 是 SecureCRT 的默认设置，`__FolderData__.ini` 是文件夹里会话的顺序，都不是会话。最多读 10000 个会话文件，超出后的第一个列为失败。

导入的字段：名称（去掉 `.ini` 的文件名）、主机、端口、用户名、备注（会话的描述）、文件夹。导入 SSH2 和 SSH1 会话；Telnet、Serial、RLogin、RDP 等会话算跳过。

- 密码不导入。SecureCRT 把密码加密存在会话文件里，Finallyshell 不解密，也不读这些行。
- 有自己的私钥文件的会话（公钥选项里设的）导入后是“私钥”认证，用这个私钥文件；SecureCRT 写的是 `.pub` 文件时，用对应的私钥。路径里的 `${VDS_CONFIG_PATH}` 是配置文件夹。用 SecureCRT 全局私钥的会话，如果它的认证方法里公钥排在密码前面，就用配置文件夹里 `SSH2.ini` 写的全局私钥文件。认不出的私钥路径（别的 SecureCRT 变量、在 macOS、Linux 上读到 Windows 路径，或者 `Sessions` 文件夹旁边找不到 `SSH2.ini` 时的全局私钥）导入后要自己选私钥文件，“说明”列会提示。
- 防火墙设置不导入：通过代理连接的会话在“说明”列写“代理没有导入”，通过另一个会话（跳板机）连接的写“跳板机没有导入”。端口转发、登录动作、终端和外观设置也不导入。

SecureCRT 的文件格式没有官方文档，导入按 VanDyke 的脚本示例和其他开源项目的 SecureCRT 读取代码整理，写在 `internal/importer/securecrt.go` 的注释里。解析尽量宽松：别的格式的行和用不到的选项忽略，缺的用默认值（SSH2、端口 22、密码认证），多行的值（二进制值，以及描述以外的列表）跳过。

### 从 MobaXterm 导入

MobaXterm 把会话存在 `MobaXterm.ini` 里。在 Windows 上，Finallyshell 先找 `%APPDATA%\MobaXterm`（安装版），再找 `Documents\MobaXterm`。便携版把它放在 `MobaXterm.exe` 旁边，要自己选。也可以选从 MobaXterm 导出的会话文件：“Export all sessions to file”或“Export sessions from this folder”导出 `.mxtsessions` 文件，“Save session to file”导出一个会话的 `.moba` 文件。中文 Windows 上保存的文件（GBK 编码）也能读。

只导入 SSH 会话，RDP、VNC、SFTP、Telnet 等其他会话跳过。导入的字段：名称、主机、端口、用户名（MobaXterm 的 `<default>` 是不指定用户名）、注释（作为备注）、文件夹（会话文件夹，和 MobaXterm 里一样嵌套；单独导出的文件夹就是同名的文件夹），以及私钥文件，作为主机的私钥文件（路径里的 `_CurrentDrive_` 就是盘符 `C`）。在 macOS 和 Linux 上，Windows 的私钥路径在本机不存在：主机是“私钥”认证但没有私钥文件，导入后再选。

- 密码不导入。MobaXterm 把密码加密存在会话之外（有主密码保护），Finallyshell 不读。
- SSH 网关（跳板机）和代理不导入：主机直接连接，“说明”列里会注明。导入后可以在连接编辑器里设置跳板机。
- 终端设置、颜色和字体、登录后执行的命令、X11 转发、MobaXterm 的 SSH 隧道都不导入。

MobaXterm 的文件格式没有官方文档，导入按 Ruzgfpegk 的 gist “.mxtsessions file format”（对 MobaXterm 26.3 逆向整理的格式说明）和其他开源工具（mobaConverterGo、mobaxterm2ssh、mobaxterm-mcp）的读取代码整理，写在 `internal/importer/mobaxterm.go` 的注释里。还没有用用户的真实文件核对过，所以解析尽量宽松：不认识的段和字段忽略，缺的字段用默认值（端口 22、密码认证），读不了的行算作失败，并标出行号。

### 从 SSH 配置文件导入

OpenSSH 客户端的配置 `~/.ssh/config`（Windows 上是`%USERPROFILE%\.ssh\config`）存在就读它；不存在，或者点“选择文件…”，可以选任意文件（文件名不限）。按 `ssh` 的读法读：

- `Host` 行的每个名字是一个连接，以这个名字命名：`Host web db` 是两个。通配模式（带 `*`、`?` 或 `!` 的名字）不是连接，但其中的设置用于匹配到的名字；第一个 `Host` 之前的行用于所有名字。每项设置取文件里第一个适用的行，和 `ssh` 一样：末尾 `Host *` 下写 `User deploy`，所有自己没写用户名的主机都用它。
- 导入的字段：`HostName`（`%h` 是名字；没写就用名字作主机）、`Port`、`User`（没写就用本机的用户名，和 `ssh` 一样）、第一个 `IdentityFile` 作私钥文件，以及 `ProxyJump`。关键字不分大小写，`Key value` 和 `Key=value` 都认，值可以加引号，`#` 是注释。
- 私钥文件路径里，`~` 保留为主目录，`%d`（主目录）、`%u`（本机用户）、`%h`（主机）、`%r`（用户名）、`%n`（名字）、`%p`（端口）和 `%%` 会展开。其他记号原样保留，“说明”列里注明。
- `ProxyJump` 指向文件里的另一个名字时，两个都导入后（或者跳板机已存在），那个连接就是跳板机，“说明”列里显示。链式的（`a,b`）用最后一跳。跳板机不是文件里的名字（`user@host:port`，或者没有对应的 `Host` 行），或者没有导入，就不设置：主机直接连接，“说明”列里注明；说明跟着勾选变：取消勾选跳板机，经过它的主机马上改成没有导入。`ProxyCommand` 也不导入，按代理注明。
- `Include` 就地读入其他文件，支持通配符；相对路径在所选文件的目录里（即 `~/.ssh`，和 `ssh` 一样）。最多读 16 层、256 个文件。
- 连接导入到顶层，没有备注。有私钥文件的主机用“私钥”认证和这个文件；其他的用密码认证，第一次连接时询问（文件里没有密码）。

列在表格下面的：只有通配模式的 `Host` 行和 `Match` 块（不支持）算跳过；不是 1 到 65535 之间数字的 `Port`（忽略）、解析不了的行（引号没有闭合）、读不了或超过限制的 `Include` 算失败。其他关键字（`LocalForward`、`CertificateFile` 等）忽略。

### 从 CSV 或 Excel 文件导入

“CSV 或 Excel 文件”导入记在表格里的服务器列表：`.csv`、`.tsv`、`.txt` 文件，或者 Excel 工作簿（`.xlsx`）里第一个没有隐藏的工作表。它没有固定的位置，所以选了就直接弹出选择文件的对话框。窗口底部的“保存模板…”保存一个 `servers.csv`（默认放在下载目录）：表头用界面的语言，还有一行示例，照着填好再导入。

第一行是表头（上面有标题行也行：前十行里第一个有主机列的行就是表头）。按表头找列，不分大小写，忽略空格、`_` 和 `-`；别的列忽略：

| 字段 | 表头 |
| --- | --- |
| 名称 | name、label、title、名称、名字、别名 |
| 主机（必需） | host、hostname、address、ip、ip address、主机、主机名、主机地址、地址、ip地址 |
| 端口 | port、端口 |
| 用户名 | user、username、login、用户、用户名、账号 |
| 密码 | password、密码 |
| 私钥 | key、private key、key file、identity file、私钥、私钥文件 |
| 文件夹 | folder、group、文件夹、分组 |
| 备注 | notes、note、description、comment、comments、备注、说明 |

- 没有主机列的文件不导入，窗口里列出读到的表头。
- 按文件里的顺序列出。空行跳过。没有主机、或者端口不在 1 到 65535 之间的行，带着行号列在表格下面，算失败。
- 主机写成 `主机:端口`（IPv6 地址写 `[IPv6]:端口`）的，导入时主机只取主机部分；端口格是空的时用这个端口（端口格有值就用端口格的）。不带方括号的 IPv6 地址不拆。写成 `用户@主机`，用户名格是空的时就用这个用户名。
- 单元格前后的空格忽略，密码格除外：密码按写的原样导入。只有空格的密码格算空。
- 文件夹写 `生产/数据库`（或者用 `\`）是嵌套的文件夹。没有文件夹列的列表导入到顶层。
- 写了私钥文件的主机用这个私钥登录，它的密码格不用。其余的用密码登录。
- 密码存进系统的密钥库，和“记住密码”一样，不会写进 `hosts.json`。表格里有一列“密码”，有密码的行显示 `••••`，不显示密码本身。

文本文件：按 Excel 保存时的编码读：“CSV UTF-8”（带字节顺序标记）、普通的“CSV”（系统的代码页，中文 Windows 上是 GBK）、“Unicode 文本”（UTF-16，用制表符分隔）。分隔符从制表符、`;`（很多欧洲语言的 Excel 这样存 CSV）、`,` 里选：按哪一个分，前十行里有一行是带主机列的表头，就用哪一个，所以表头上面的标题行不影响（几个都行时，用表头里认得的列最多的那个）。没有主机列的文件看第一行：有制表符就是制表符；`;` 比 `,` 多就是 `;`；否则是 `,`。第一行写 `sep=;` 的，按它说的来。引号按 Excel 的写法读。

Excel 文件：单元格都按文字读，数字不带末尾的 `.0`，公式读 Excel 或 LibreOffice 保存时一起存下的结果。不套用数字格式（日期、货币）。Excel 97-2003 工作簿（`.xls`）、设了密码的工作簿、OpenDocument 表格都读不了：窗口会请你另存为 `.xlsx` 或 CSV。有些系统导出的 `.xls` 其实是文本文件，按文本读。

限制：文件最大 10 MB，前 10000 行以后的不读（列出第一个没读的行）。工作簿的每个部分解压后最多 32 MB，工作表最多大约一百万个单元格。

## 连接编辑器

“新建连接”和“编辑连接”打开一个单独的窗口，左边是页面，下面是“确定”“取消”。

### SSH 连接

- 名称、主机、端口、备注（多行）。
- 认证方法（密码或私钥）、用户名，然后是密码，或者私钥文件（“浏览…”选文件）和私钥密码。
- “记住密码”（私钥是“记住私钥密码”），默认开。
- “启用 exec 通道（服务器监控）”。

错误提示显示在对应的输入框下面。

<a id="terminal-page"></a>

### 终端

- 终端类型：发给服务器的 `TERM`，默认 `xterm-256color`。
- 退格键发送、删除键发送、字符编码：每一项的第一个选择是“默认：…”，跟随 [选项的“终端”页](#terminal-defaults)；也可以给这个主机单独选。可选的值和那一页一样。

在 `hosts.json` 里是 `backspace`（`del`、`ctrl-h`）、`delete`（`vt220`、`del`、`ctrl-h`）和 `encoding`（名字见[终端](#terminal-defaults)），没有就是“默认”。以前版本保存的主机没有 `backspace`，所以跟随全局设置，全局默认还是 `^?`，行为不变。

### 代理和跳板机

类型选“不使用”（直接连接）、SOCKS5、HTTP 或“跳板机”。

- SOCKS5 和 HTTP（`CONNECT`）填代理的主机、端口（默认 1080 / 8080），代理需要认证时填用户名和密码（HTTP 是 Basic 认证）。SOCKS5 由代理解析主机名，所以主机可以填只有代理那边认识的名字。
- “跳板机”从已保存的其他连接里选一个（不能选自己），相当于 `ssh -J`：先登录跳板机，再由跳板机的 SSH 服务器转发到这台主机（跳板机要允许 TCP 转发）。跳板机自己也可以设代理或跳板机，按顺序一跳一跳连过去。绕回来形成循环时，编辑器和连接时都会提示 “跳板机形成了循环：a → b → a”。
- 每一跳都和直接连接它一样：第一次连接时确认它的主机指纹，用它自己的登录方式和密码。连接时，还不知道的密码按顺序一个一个问：先问主机自己的，再问它的代理的，再问各个跳板机的。标题写“输入跳板机密码”或“输入代理密码”，下面写是哪个主机、为了连接谁。主机改成走跳板机后重新连接，也会先问新跳板机的密码。
- 代理密码和主机密码一样存在系统的凭据存储里（跟着“SSH 连接”页的“记住密码”），不写进 `hosts.json`。
- 出错时说明是哪一跳：“代理 1.2.3.4:1080：连接被拒绝：端口没有开放代理服务” “跳板机 web-1：认证失败：…”“跳板机 web-1：无法连接到 10.0.0.5:22：…”。
- 关闭或断开会话时，跳板机的连接一起关闭。

<a id="tunnels-page"></a>

### 隧道

SSH 端口转发。表格列出“类型”“监听”“转发到”“启用”，下面是“添加…”“编辑…”“移除”（双击一行也是编辑）。添加和编辑用同一个对话框。

- 本地（`-L`）：在本机监听，每个连接经服务器转发到目标（目标地址按服务器那边解析）。
- 远程（`-R`）：在服务器上监听，每个连接转回本机，再由本机连到目标。
- 动态（`-D`）：本机的 SOCKS5 代理，由服务器去连客户端要访问的地址。只支持 CONNECT，不需要认证。地址可以是 IPv4、IPv6 或域名（域名由服务器解析）。SOCKS5 服务端是自己写的一小段代码（`sshx/forward.go`），现有依赖里没有现成的。

默认只监听 `127.0.0.1`（远程隧道是服务器的 `127.0.0.1`），只有同一台机器能连。勾选 “允许其他计算机连接”才能填别的监听地址（默认 `0.0.0.0`），同时显示警告：谁都能用这条隧道，不需要登录。远程隧道还要服务器的 `GatewayPorts` 允许。

远程隧道的监听地址只能是 IP 地址（IPv4 或 IPv6）或 `localhost`（就是 `127.0.0.1`）。SSH 库会在本机解析主机名，而不是在服务器上，所以不接受主机名。手改 `hosts.json` 写了主机名的，这条隧道启动时报错，说明原因，表格里这条隧道带一个警告图标。

端口必须是 1 到 65535，目标主机必填。同一台机器上已有隧道监听同一个端口时，对话框提示 “已有另一条隧道监听这个端口”。“随会话启动”关掉的隧道不自动启动，但可以在右下的“隧道”页手动启动。

### 按键和其他行为

- 回车等于“确定”（备注里回车是换行），Esc 等于“取消”。
- 同时只开一个编辑器。已经开着时再点新建连接或编辑，只会把开着的那个提到前面，里面没保存的内容不会丢。
- 修改已经打开会话的主机，下次连接时生效。
- 编辑期间主机在连接管理器里被删除了，“确定”只提示“此连接已被删除”，不会把它存回去。

## 服务器监控和系统信息

左上显示当前会话的服务器：IP、运行时间、负载、CPU、内存和交换、内存占用前几的进程、网速和延迟曲线、磁盘。每 2 秒通过 SSH 读取一次 `/proc`，所以只支持 Linux 服务器。未连接时显示 FinalShell 那样的空白占位（“-”、0%）。点进程列表打开[进程页](#进程页)。

网速曲线默认显示流量最大的网卡：服务器开机以来字节数最多的那个，从不选 `lo`。曲线右上角的网卡名点开是一个菜单：“自动（流量最大）”和 `/proc/net/dev` 里的每个网卡及其当前网速，先是其他网卡，然后是 Docker 的 `veth*`，最后是 `lo`。选一个网卡就勾上或取消勾选，勾了几个时曲线显示它们的合计，标签写成“eth0 + wg0”。每个网卡有自己的历史，所以一选就能看到最近两分钟；后来才出现的网卡（比如 VPN）下一次读取时就进菜单。选择按主机保存（`hosts.json` 的 `monitorIfaces`，随主机同步）。选中的网卡服务器上已经没有时跳过它；选中的都没有了，曲线回到流量最大的网卡，标签写“eth0（自动）”，提示里列出缺的网卡。它们在菜单里仍然勾着，标着“不存在”，直到取消勾选。

IP 下方的“系统信息”按钮弹出主机名、系统（`/etc/os-release`）、内核、架构、CPU 型号和核数、内存、运行时间、IP 地址、硬盘，“复制”把这些复制成纯文本。每次打开时通过一个 exec 通道读取一次，用一段 POSIX sh 脚本，BusyBox 也能跑。缺 `lscpu`、`nproc`、`ip` 之类的工具时跳过或换用别的。

## 终端

右上是终端。会话断开后保留最后的画面，顶部出现“重新连接”。

### 查找

Ctrl+Shift+F（macOS 是 Cmd+F）在终端右上角打开查找栏（MyGo 的 `ui.FindBar`）。

- 边输入边用插件的 `Search` 搜屏幕和滚动历史，高亮所有匹配，显示“第几项，共几项”。
- 回车到下一个（往上，更早的输出），Shift+回车到上一个。F3 / Shift+F3（macOS 是 Cmd+G / Shift+Cmd+G）也行。
- Esc 或“完成”关闭查找栏，结束搜索，键盘回到终端。
- 再按一次快捷键时全选查找框里的文字。
- 每个会话的查找栏分开。
- 不区分 ASCII 字母大小写（插件就是这样）。

### 全屏

Ctrl+Shift+Enter（macOS 是 Cmd+Enter）隐藏左边栏和下面的文件面板，只留终端，窗口也进入系统的全屏。再按一次退出全屏。

- Esc 只在没有 shell 接收它时退出全屏（新标签页、断开的会话），连接着的终端里 Esc 照常发给 shell（vi 要用）。
- 窗口本来就是系统全屏的，退出程序的全屏时保持系统全屏。
- 用系统的办法（macOS 的绿色按钮）退出系统全屏，也一起退出程序的全屏。

### 命令输入框

终端下面是一行命令输入框，和 FinalShell 的命令输入框一样：一个终端图标、没有占位文字的输入框，以及最右边的“历史”按钮。默认打开；“选项 › 终端 › 命令输入框”可以关掉它，或者关掉其中某个弹出列表，那里也列出了它的按键（见[终端 › 命令输入框](#终端--命令输入框)）。

- 回车把输入框里的内容加一个回车发给 shell，和在终端里输入一样（经过会话的编码转换），然后清空输入框。终端的按键不受影响：只有在输入框里打字时，键盘才在输入框。
- Tab 补全光标处的词：
  - 像路径的词（含 `/`，或以 `~`、`.` 开头）打开路径选择，分多列列出服务器上的文件夹：先文件夹（以 `/` 结尾），再文件，图标和文件面板的图标主题一样，隐藏文件排在最后。输入可以筛选（不区分大小写），筛选为空时按退格键回到上一级，方向键移动，回车或 Tab 插入。插入文件夹后接着列出它里面的内容；插入文件后加一个空格。名字里的空格等会被 shell 另作解释的字符用 `\` 转义。最多列出 2000 项，后面显示“还有 N 项”。含有控制字符（换行、转义序列）的名字以转义形式变暗显示，不能插入：发送出去的话，换行后面的内容会作为另一条命令执行。含有控制字符的命令名和服务器历史里的行不列出。
  - 否则，第一个词打开命令补全：服务器 PATH 里以它开头的命令。每次连接用一个 exec 通道读取一次：有 bash 时用 `compgen -c`（包括内置命令），没有 bash 时列出 `$PATH` 里的每个文件夹。关闭了“启用 exec 通道”的主机改为通过 SFTP 列出 `/usr/local/sbin`、`/usr/local/bin`、`/usr/sbin`、`/usr/bin`、`/sbin` 和 `/bin`。
  - 其他词打开当前文件夹的路径选择。
- 相对路径从 shell 报告的工作目录（OSC 7）算起；shell 不报告时从文件面板的文件夹算起。`~` 是主目录。文件夹通过会话的 SFTP 读取，所以没有 SFTP 的服务器会在弹出列表里显示错误，发送和历史照常可用。
- ↑、Alt+H 或“历史”按钮打开历史列表（按钮让键盘留在输入框，列表打开时再点就关闭；关掉历史列表后按钮隐藏）：以前发送过的、以已输入内容开头的命令，最新的在最下面，紧挨输入框。↑ ↓ 移动；← → 高亮选中命令里的一个字段（词），这样可以从 `yum -y install epel-release` 里单独取出 `epel-release`。回车把这个字段插入到光标处的词的位置；没有高亮字段时，把整条命令放进输入框。“清空列表”删除这台主机的历史。
- 历史由程序按主机保存：从输入框发送的每条命令，每条只留一次，最新的在最后，条数不限（文件超过 10 MB 时从最旧的删起，见 [configuration.md](configuration.md#命令历史)）。后面接着服务器上 `~/.bash_history` 和 `~/.zsh_history` 里的命令，每次连接通过 SFTP 读取一次，所以在终端里输入的命令也会出现（bash 在 shell 退出时才写历史文件）。
- Esc 关闭弹出列表，再按一次 Esc 键盘回到终端。“聚焦命令输入框”（Ctrl+Shift+L，macOS 上是 Cmd+Shift+L）在输入框和终端之间切换键盘。
- 新标签页没有输入框。正在连接或已断开的会话里，输入框显示为禁用。

暂不支持：一次发给多个会话，以及快捷命令按钮。

### 外观：字体、配色、背景图片

选项的“终端 › 字体”“终端 › 配色”“终端 › 背景图片”三页管终端的外观。改了立刻应用到所有打开的终端（`SetFont`、`SetTheme`），新开的终端也用新设置；连接过程中改了，连上后也会补上。每页下面有“恢复默认”，上面有预览：示例提示符、彩色 `ls`、带连字的代码，用界面控件画，用的是同样的字体、配色和背景。

字体：

- 字体名称：输入时提示系统里已安装的等宽字体（来自 `ui.FontFamilies`）。可以写逗号隔开的多个，用第一个装了的。空着是默认的 JetBrains Mono, Cascadia Mono, Consolas, Menlo, DejaVu Sans Mono, monospace。
- 字号：6 到 48，默认 13.5。
- 行高：字体本身行高的 0.8 到 2 倍，默认 1。
- 粗细：细 300、常规 400、中等 500、半粗 600、粗 700。插件的粗体总是比它重 300、至少 700，没有单独的粗体粗细。
- 连字：默认开，关掉是 `-calt`、`-liga`。

改字体会结束终端里的 Ctrl+= 缩放；只改配色不会。

配色：

- Ghostty 自带的几百个主题（`terminal.GhosttyThemes()`），也包括 Ghostty 主题目录里用户自己的。
- 搜索框按名称过滤。每行带背景色和几种颜色的小样，预览下面是 16 种 ANSI 颜色。
- 默认 Tomorrow Night。主题文件不见了时用默认的。
- 应用的浅色和深色外观（选项 › 常规 › 外观）用同一个配色，所以只有一个选择，同时设给插件的 `Theme` 和 `DarkTheme`。

背景图片：

- “选择…”用系统的打开对话框选 PNG、JPEG、GIF、WebP 或 BMP 图片（文件 64 MB 以内，最多 1 亿像素）。先解码确认能显示，再复制一份到配置目录（`finallyshell/background-<时间>.<扩展名>`），所以原图移走、删掉都没关系。换图或 “移除”会删掉旧的副本。
- 填充方式：铺满（裁剪）、完整显示或平铺。不透明度：5% 到 100%，默认 30%。
- 不是图片、读不了的文件只显示错误，不复制，也不替换现在的图。
- 副本不见了（或 `settings.json` 里的名字不是副本）时，这一页显示“背景图片不见了：请重新选择，或者移除。”可以重新选择或移除。
- 图片的读取和解码都不在界面线程上。启动时不读；第一次要显示时在 goroutine 里读，读完再通过 `App.post` 显示，没读完时终端只显示配色的背景色。读的过程中换了或移除了图片，旧的结果直接丢掉。
- 超过 3840 像素（长边）的图片缩小后再保存在内存里（磁盘上的副本仍是原文件）。JPEG 按 EXIF 方向摆正。

怎样画：终端都用 `Transparent: true` 创建，应用自己在终端下面画背景：先是配色的背景色，再画图片，再盖一层 (1 − 不透明度) 的背景色，所以文字一直在配色背景上。程序自己设的背景色（OSC 11、单元格背景）照常画。

在 `settings.json` 里是 `termFontFamily`、`termFontSize`、`termLineHeight`、`termFontWeight`、`termNoLigatures`、`termTheme`、`termBackground`（副本的文件名）、`termBackgroundFit`（`contain` 或 `tile`；没有是铺满）、`termBackgroundOpacity`（百分比）。没有就是默认值。

## 文件面板

右下的“文件”页用 SFTP 浏览服务器：左边目录树，右边文件表格（可多选），路径栏可以直接输入路径。

### 文件图标主题

文件面板按文件名显示图标：`docker-compose.yml` 是 Docker 图标，`main.go` 是 Go 图标，`src/` 是 src 文件夹图标，展开的文件夹换成打开的样子。用的是 VS Code 的文件图标主题格式，所以 VS Code 的图标主题都能用。在选项的“文件管理 › 文件图标主题”页选择，上面有预览，选了立刻生效。

- 内置：Material Icon Theme（默认）、Seti（VS Code 自带的那个），以及“简洁”（只有文件和文件夹两个图标，就是以前的样子）。
- “从 VSIX 安装…”：选一个 `.vsix` 文件（VS Code 扩展包，比如从 [Open VSX](https://open-vsx.org) 下载的），确认它有能读的图标主题后原样复制到配置目录的 `icon-themes/<发布者>.<名称>.vsix`。同一个扩展的新版本替换旧的。装好后自动选中。最大 50 MB。列表里的删除按钮删掉这个副本。
- 自动列出 VS Code、VS Code Insiders、VSCodium、Cursor、Windsurf 里已经装了的图标主题（`~/.vscode/extensions` 等，Windows 上在 `%USERPROFILE%` 下），直接读，不复制。已卸载的（`.obsolete`）跳过，同一个扩展只列最新版本。“刷新”重新查找。
- 选中的主题后来不见了或读不出来时，面板显示 Material Icon Theme，并在选项页说明原因。

只读取主题的 JSON 和它引用的 SVG、PNG、字体，扩展里的代码不会运行。引用到扩展外面的路径直接忽略。用字体做图标的主题（Seti 用 WOFF，file-icons 用 WOFF2）先转成 TrueType 再注册给界面。按 VS Code 的规则匹配：先文件名，再扩展名（最长的优先，`a.test.ts` 先找 `test.ts`），再语言（文件名到语言的对应表来自 VS Code 自带的语言扩展），最后是默认的文件图标。和 VS Code 一样，只在应用是浅色时用主题的 `light` 部分；深色外观下用主题本来的图标。切换外观时图标立刻跟着换。

在 `settings.json` 里是 `fileIconTheme`：没有是 Material，`minimal` 是简洁，`bundled:seti` 是 Seti，其他是 `<发布者>.<名称>/<主题 ID>`。

内置的两个主题都是 MIT 协议，许可证在各自的 VSIX 里（`internal/fileicons/bundled/`）。更新它们和语言表：改 `internal/fileicons/internal/gen` 里的版本号，运行 `go generate ./internal/fileicons`（需要 git 和网络）。

### 软链接

文件表格里每个软链接的图标左下角有一个小箭头，名字后面用浅色字显示它指向哪里（`bin → usr/bin`）。和 `ls -l` 一样，这是链接里写的原样，相对或绝对路径，不解析。

- 指向文件夹的链接显示成文件夹，排在文件夹一组，双击进入。
- 指向文件的链接“类型”是“链接”，“大小”是它指向的文件的大小，“权限”是链接自己的。
- 目标不存在（或链接成环）的是失效的链接：名字是红色，“类型”是“失效的链接”，没有大小，双击不打开。目标没有权限查看的不算失效。
- 列目录时同时解析最多 16 个链接（每个要 `readlink` 和 `stat` 两次往返），所以链接多的目录（比如 `/usr/lib64`）不用一个一个等。
- 左边的目录树不显示箭头。

### 文件操作

在文件表格和目录树的右键菜单里可以重命名、删除、新建文件和文件夹、修改权限：

- 文件表格的菜单有“新建文件夹”“新建文件”“重命名”（选中一项时）、“修改权限”（选中一项或多项时）和“删除”（选中一项或多项时）。表格有焦点时，F2 重命名选中的项目，Delete（macOS 上也可以用 Cmd+Backspace）删除选中的项目。
- 目录树的菜单作用于右键点击的那个文件夹，不会打开它：打开、上传文件、上传文件夹（传到这个文件夹）、新建文件夹、新建文件、重命名、修改权限、删除、刷新、复制路径。`/` 没有重命名、修改权限和删除。

重命名、新建文件夹和新建文件会询问名称。重命名时和 Finder、资源管理器一样，默认选中扩展名之前的部分。名称为空、是 `.` 或 `..`、含有 `/` 的不能用，文件夹里已经有的名称也不能用：重命名不会覆盖别的文件，新建文件也不会清空已有的文件。服务器返回的错误（比如没有权限）显示在对话框里，对话框不关闭。

修改权限会询问一个数字权限，例如 755：3 位数字，需要设置 setuid、setgid 或粘滞位时用 4 位（例如 4755）。只选中一项时，默认填入该项目当前的权限。不是 3 或 4 位八进制数字的权限会被拒绝，服务器返回的错误显示在对话框里，对话框不关闭。

删除前总是先确认。文件夹连同其中的所有内容一起删除。不会跟随链接：删除指向文件夹的链接只删除链接本身，不动它指向的文件夹。一个文件夹里的文件同时最多删除 16 个，大文件夹不用每次等一个往返。删除还在进行时取消对话框会停止删除，已经删掉的不会恢复。

操作完成后重新列出文件夹，表格里选中重命名或新建的项目。当前文件夹（或它所在的文件夹）被重命名时，面板跟到新路径；被删除时，回到它所在的文件夹。

### 上传和下载

上传：把文件或文件夹从资源管理器 / Finder 拖到文件表格（传到当前目录）或目录树的某个文件夹上。也可以用工具栏的上传按钮或右键菜单选文件、选文件夹。

下载：选中文件或文件夹，点下载按钮。存到下载目录，默认是系统的“下载”文件夹（`~/Downloads`），可以在选项的“传输”页修改。右键菜单的“下载到…”自己选位置。“传输”页勾选“每次下载时询问保存位置”后，下载按钮每次都先用系统的选择文件夹对话框问保存位置。

### 打包传输

SFTP 每个文件都要来回好几次，传大量小文件的文件夹很慢。“打包下载”和“打包上传…”改用 tar 和 gzip 打包传输，和 FinalShell 的打包传输一样：

- “打包下载”在文件表格的右键菜单（选中文件夹或多个项目时有，单个文件没有）、目录树的右键菜单（`/` 以外的文件夹）和工具栏下载按钮的右键菜单里（右键点它；左键点击仍是下载）。服务器在这些项目所在的文件夹运行 `tar -czf -`，应用读取数据流，一个文件一个文件地解包到下载目录。
- “打包上传…”在文件表格和目录树的右键菜单，以及工具栏两个上传按钮的右键菜单里（右键点它们；左键点击仍是选文件或文件夹），选择文件夹。应用把它们打包成数据流，服务器在目标文件夹用 `tar -xzf -` 解包，文件夹不存在时先创建。文件归登录的用户所有，与本机上的所有者无关。

两个方向都是流式的，两边都不产生临时压缩包。每次打包传输是队列里的一个传输，和其他传输一样：“传输”页显示“打包下载”或“打包上传”、按文件字节数计的进度（传输开始后同时统计总大小），以及正在打包或解包的文件。取消会停止服务器上的 tar 并关闭它的通道，本机写了一半的文件会被删掉。开始前目标位置已有同名项目时询问一次，然后覆盖。文件夹（包括空文件夹）、软链接、权限和修改时间都保留；所有者、设备文件和套接字不保留。

服务器上没有 `tar` 或 tar 出错时，传输失败并显示它的输出，“改用 SFTP 重试”按普通方式重新传这些项目，每个一个传输。

下载的解包是安全的：绝对路径、含 `..` 或不在所选项目之下的名字会让传输停止；不会经过软链接写入（要放文件夹的位置是软链接时，像 tar 一样换成文件夹）；硬链接只能指向这次下载写出的文件；去掉 setuid、setgid 和 sticky 位。gzip 数据流会读到结尾，校验和或大小对不上时传输失败，并提示解包出的文件可能有误。在 Windows 上，Windows 不允许的名字（如 `a:b` 或 `CON`）会让传输失败并显示这个名字，不会被改名。

有些软链接不创建，其余内容照常下载：

- 指向下载目录以外的链接：看它的目标，以及全部解包后经过其他链接实际到达的位置（如 `b -> ..` 时的 `a -> b/../..`）。
- 在 Windows 上，Windows 不允许用户创建链接时的所有链接（开发者模式下或管理员可以创建）。

这时传输仍算完成，并显示一行提醒，如“2 个链接没有创建：它们指向文件夹以外”，鼠标悬停列出这些链接。这种情况不提供“改用 SFTP 重试”。

### 传输页

右下的“传输”页显示进度、速度、剩余时间和取消按钮。同时最多跑 3 个，其余排队。

- 目标位置已有同名项目时先询问是否覆盖。
- 失败或取消的可以“重试”：在同一个会话里用它现在的连接重新排队；会话已关闭或未连接时不能重试。
- 下载完成后可以“打开”（用系统默认的程序；没有能打开它的程序时在文件夹中显示），或 “在文件夹中显示”。

### 下载列表弹出框

文件面板工具栏最右边的“下载列表”按钮和 FinalShell 的一样。有传输在进行时按钮上显示数目。点开是一个弹出框：

- 第一行是下载目录（太长时省略中间部分）、“更改…”和“在访达中显示”（Windows 是 “在资源管理器中显示”，Linux 是“在文件夹中显示”；目录不存在时先创建）。
- 下面是最近的传输（上传和下载），最新的在最上面，每行和“传输”页一样。
- 底部是“清除已完成”。

弹出框和“传输”页是同一个队列：“传输”页按开始的顺序排，弹出框反过来。

### 应用图标上的进度

有传输在进行时：

- macOS 的 Dock 图标显示数目和总进度。
- Windows 的任务栏按钮显示总进度（MyGo 在 Windows 上没有图标角标）。
- 支持 Unity launcher API 的 Linux dock 两样都显示。

总进度算的是正在跑、已知大小的传输的字节数。全部结束后清除。进度每秒最多更新 4 次，数目一变立刻更新。

## 编辑远程文件

和 FinalShell 一样，在文件表格里双击文件（或选中后按回车），或右键“编辑”，在编辑器窗口里打开。双击文件夹仍然是进入文件夹。

编辑器用 MyGo 的代码编辑器（`ui/editor`）：30 多种语言的语法高亮、查找和替换、跳转到行、撤销、多光标、折叠。语言按文件名认，没有扩展名的脚本看第一行的 `#!`。nginx、systemd 这类没有的语言按纯文本显示，`.conf` 是 MyGo 认作 TOML 的。

### 窗口

一个编辑器窗口（主窗口的子窗口，1000×700，可以调整大小），每个文件一个标签。标签记着它来自哪个会话。窗口标题是选中标签的 `主机:路径`，有没保存的修改时标签上显示一个圆点。再打开已经打开的文件只切换到它的标签。

工具栏是保存、撤销、重做、搜索、替换、跳转到行、自动换行、从服务器重新加载。下面的状态栏显示“已保存”或保存的错误、语言、行和列、编码、换行符（编码和换行符点一下可以换）。

### 按键

- Ctrl+S（macOS 是 Cmd+S）保存。
- Ctrl+W（macOS 是 Cmd+W，“关闭标签”改了键的话那个键也行）关闭标签。关掉最后一个标签就关闭窗口。
- Ctrl+Tab / Ctrl+Shift+Tab 切换标签。
- Esc 只给编辑器（关掉查找栏、跳转栏、补全，多个光标回到一个）。和别的子窗口不同，Esc 从不关闭编辑器窗口：编辑时常按 Esc，误按一下不该关掉窗口。关闭窗口用它的关闭按钮，或关掉最后一个标签。
- 编辑器自己的键（Ctrl+F 查找、Ctrl+H 替换、Ctrl+G 跳转到行、Ctrl+D 选下一个……，macOS 上是 Zed 的键）见 MyGo 的文档。
- 编辑器窗口里没有主窗口的快捷键。

### 读取

在 goroutine 里通过 SFTP 把文件整个读进内存（不写临时文件），大文件显示进度，读完通过 `App.post` 显示。

- 超过 10 MB 的文件先问（“仍然打开”）。
- 前 8000 个字节里有 NUL 的文件当作二进制文件，不打开。“用默认程序打开”把它下载到应用的缓存目录（`<缓存目录>/finallyshell/opened/<时间>/`，超过一天的下次打开时删掉），再用系统的默认程序打开。这个副本改了不会传回服务器。

### 保存

先在同一个目录里写一个隐藏的临时文件（`.<文件名>.finallyshell-<随机>.tmp`），设成原文件的属主（属主不一样时）和权限（包括 setuid 等位），再用 `posix-rename@openssh.com` 替换原文件。服务器没有这个扩展（或它失败了）就先删掉原文件再改名（SFTP 第 3 版的改名不能覆盖已有文件，所以中间有一小段时间文件不存在）。这样读这个文件的程序只会看到旧的或新的，连接中途断开原文件也不受影响。

替换会得到一个新文件，丢掉原文件的扩展属性、ACL、SELinux 标签和硬链接，而且只有 root 能把文件交给别的用户。所以这些情况下改成就地写（截断再写）：

- 文件是符号链接（写到它指向的文件，链接保持是链接）；
- 目录没有写权限；
- 改不了属主或权限；
- 改名被拒绝（比如 `/tmp` 这样的粘滞目录）。

就地写保留文件的一切，但不是原子的：写到一半失败文件会被截短（编辑器里的内容还在，可以再存一次）。

建临时文件因为别的原因失败（比如磁盘满了）时报错，不动原文件。保存时文件已经不见了的话重新创建。

### 冲突

记下打开（或上次保存）时服务器上文件的修改时间和大小，保存前再查一次。变了（或者文件被删了）就问“覆盖”还是“重新加载”。重新加载算一次编辑，“撤销”可以找回自己的内容。

### 换行符和编码

- 保持文件原来的换行符（CRLF 或 LF；两种都有的文件按多的那种保存）。
- 默认 UTF-8，开头的 BOM 保持。
- 不是有效 UTF-8 的文件，上面提示可能是 GB18030（或 GBK），可以“以 GB18030 重新打开”。原样保存时不是 UTF-8 的字节也原样写回。
- 状态栏可以换成 GBK 或 GB18030（`golang.org/x/text`）。还没修改时按新编码重新读原来的字节，改过之后只改变保存用的编码。GBK 里没有的字符（比如 emoji）保存时报错，并指出在第几行。

### 没保存的修改

- 关闭标签、用关闭按钮关闭窗口时先问“不保存 / 取消 / 保存”。窗口是“全部保存”：存好的标签关掉，全存好了窗口就关。
- 退出程序时，确认框里也写上有几个文件没保存。这一项不管“关闭窗口前确认”开没开都问。
- 主窗口隐藏到托盘时，有没保存修改的编辑器窗口不关。

### 断开的会话

会话断开时编辑器里的内容保留，上面提示没有连接，“保存”不能用。重新连接后用会话新的 SFTP 连接保存。会话标签关掉了的话，用同一个主机的另一个已连接的会话保存。

不做：用 sudo 保存。没有写权限的文件保存时报“没有权限”。

## 隧道页

右下的“隧道”页列出当前会话的隧道。每条显示：

- 状态：“正在启动…”“监听中”“已停止”，或出错的原因，比如“端口 127.0.0.1:8080 已被占用” “服务器没有监听 …：端口在服务器上已被占用，或不允许转发”；
- 当前和累计连接数；
- 上下行字节数；
- 上一个连不上目标的连接的原因。

每行有“启动”或“停止”。标签上的数字是正在监听的隧道数。

- 会话连接成功后启动已启用的隧道。某条隧道失败（比如端口被占用）只影响它自己，会话照常连接。
- 断开、连接断掉或关闭会话时全部停止并释放端口。重新连接时按主机当前的设置重新启动。
- 经过代理或跳板机连接时，隧道走的是到这台主机本身的连接。
- “编辑隧道…”打开连接编辑器的“隧道”页。

## 进程页

右下的“进程”页是当前会话的进程管理器，相当于 FinalShell 的“高级进程管理”。点侧栏的进程列表也会打开它。

- 表格列出所有进程的 PID、用户、内存（RSS）、CPU %、名称、命令行和可执行文件路径。点列标题按该列排序，再点一次反过来；默认按 CPU 从高到低。上方的筛选框匹配名称、命令行和用户，不分大小写，旁边的数字是显示了多少个。
- 这一页显示时每 2 秒重新读取一次，切到别的页或别的会话时完全不读。列表变动时选中行跟着它的进程走。“刷新”立即读取。
- CPU % 是进程从上次读取以来占用单个 CPU 的比例，用 `/proc/<pid>/stat` 里的 CPU 时间算，和 `top` 一样：多线程的忙进程可以超过 100%。第一次读取显示 `ps` 给出的进程整个生命期的平均值（BusyBox 的 `ps` 没有，显示 0）。
- 其他用户的进程的路径要 root 才能读，显示“-”。
- 双击、回车或右键菜单的“打开详情”在列表下方用一个标签打开这个进程，标签名形如 `7267-java`，左边是 PID、名称、用户、完整命令行、可执行文件路径和工作目录，右边是环境变量。标签上的按钮把这些全部复制成文本，或重新读取；环境变量的右键菜单复制值、一行 `名称=值`，或全部。要 root 才能读的项显示“-”和“需要 root 权限”。进程已经退出时会说明。标签点 × 关闭；列表和标签之间、字段和环境变量之间的分隔条都可以拖动。
- 行的右键菜单还有“复制 PID”“复制命令行”“发送信号”（SIGTERM、SIGKILL、SIGHUP、SIGINT、SIGSTOP、SIGCONT）和“结束进程…”。每个信号都先确认。“结束进程”发送 SIGTERM；3 秒后进程还在运行时，对话框提供“强制结束”，发送 SIGKILL。服务器拒绝时，对话框显示服务器的原话，比如“服务器拒绝：Operation not permitted”。对话框打开期间已经退出的进程不会收到信号，即使这个 PID 此时已被别的进程使用：对话框显示“进程已经结束，没有发送信号。”
- 会话断开时保留最后的列表，变灰，上方是和终端一样的重新连接条。不是 Linux 的服务器显示“仅支持 Linux 服务器”；关闭了服务器监控的主机显示监控已关闭：这一页用的是同样的 exec 通道。

每次读取是一段通过 exec 通道运行的 POSIX sh 脚本，和服务器监控一样：`ps` 读用户、内存和命令行，`cat` 所有 `/proc/<pid>/stat` 读名称和 CPU 时间，一次 `ls -l` 读 `/proc/<pid>/exe` 链接得到路径。BusyBox 的 `ps` 和 `ls` 也能跑，并且不列出脚本自己的进程。详情在打开标签时读取一次 `/proc/<pid>/cmdline`、`exe`、`cwd` 和 `environ`；信号用 `kill` 发送，脚本先核对 `/proc/<pid>/stat` 里这个 PID 的启动时间和列表读到的是否一致。

## 网络页

右下的“网络”页是当前会话的网络监控，相当于 FinalShell 的“高级网络监控”：哪些进程在监听哪些端口，谁连着它们，各自传了多少数据。

- 表格每个监听中的 socket 一行（处于 LISTEN 的 TCP，以及等待数据包的 UDP socket），每个有其他连接（它自己发起的连接）的进程也一行：PID、名称、监听 IP、端口、协议、远程 IP 数、连接数、上传和下载速度、已上传和已下载的字节数。连到某个监听 socket 的连接都算在它下面，不论是哪个进程持有（fork 出来的 `sshd`、nginx 的 worker）；几个进程共用的 socket 算在 PID 最小的那个下面。点列标题按该列排序。筛选框匹配名称、PID、监听地址和端口，以及这一行的连接的远程地址。
- 这一页显示时每 2 秒重新读取一次，切到别的页或别的会话时完全不读；“刷新”立即读取。行变动时选中行跟着它的 socket 或进程走。
- 上传是服务器发出的，下载是服务器收到的。速度是每个 TCP 连接两次读取之间字节数（`ss -i` 的 `bytes_acked` 和 `bytes_received`）的差：新连接在下一次读取之前显示 0。UDP 没有 TCP 意义上的连接，它的 socket 的计数显示“-”。
- 不是 root 时读不到其他用户的 socket 属于哪个进程：这些连接放在“-”这一行，数量旁边写着“需要 root 才能看到其他用户的进程”。TIME-WAIT 状态的连接不属于任何进程。
- 双击、回车或右键菜单的“查看连接”在表格下方用一个标签打开这一行，标签名形如 `0.0.0.0:80` 或 `7267-java`，每个连接一行：归属地（只在有位置数据时，见下）、IP、端口、状态、上传和下载速度，以及总量。繁忙服务器的标签只显示前 5000 个连接，并说明这一点。连接的右键菜单复制它的 IP 或地址，追踪到它的路由，开启在线查询时还可以在线查询它。
- 会话断开时保留最后一次读取的结果，变灰，上方是重新连接条。不是 Linux 的服务器和关闭了服务器监控的主机会说明，和进程页一样。

每次读取是一段通过 exec 通道运行的 POSIX sh 脚本：`ss -tunapiH`（iproute2），用 `awk` 只保留 TCP 信息里的字节数。没有 `ss` 时（比如 BusyBox）读 `/proc/net/tcp`、`tcp6`、`udp` 和 `udp6`，通过 `/proc/<pid>/fd` 里的 socket 链接找到每个 socket 的进程，从 `/proc/<pid>/stat` 读进程名；`/proc` 没有字节数，速度和总量显示“-”。

### IP 归属地

程序里不带任何 IP 位置数据；没有数据时不在任何地方查询：表格只显示 IP 地址，没有“归属地”列。

- 第一次显示网络页时，表格上方的提示条问“显示 IP 地址的归属地？需要下载约 11 MB 的位置数据（ip2region）。”，按钮是“下载”“暂不”和“不再询问”。
  - “下载”从 GitHub 下载 [ip2region](https://github.com/lionsoul2014/ip2region) v3.18.0 版的 `ip2region_v4.xdb`，保存到配置目录的 `geo/` 里，进度显示在提示条上，可以取消。文件先用临时名字写入，SHA-256 和程序记录的一致才保留；下载失败或取消不留下任何文件，提示条提供“重试”。数据在后台读进内存，每次读取都再检查校验和。
  - “暂不”在程序下次启动之前不再显示提示条。
  - “不再询问”关闭归属地（`geoLocations` 为 `"off"`），直到在选项里打开。
- 有数据时，连接显示每个地址的国家、地区、城市和运营商，来自数据本身：中国境内是中文名称，其他地方多为英文。内网、回环、链路本地、CGNAT（100.64.0.0/10）和组播地址显示“局域网”，从不查询。
- IPv6 地址需要单独的数据文件，再下载约 37 MB：第一次出现 IPv6 对端时提示条会询问（`geoLocationsV6`）。
- 在线查询默认关闭，在选项里打开（见[网络监控](#网络监控)）。打开后，显示出来的行里数据中没有城市或运营商的地址会发送给 ip-api.com，每次请求 100 个，按程序的语言返回中文或英文名称，并按它返回的计数遵守每分钟 15 次请求的限制；它返回 429 时改问 ip.sb，每次一个地址。查询结果补上数据缺的部分，在 `geo/cache.json` 里保存 30 天。连接右键菜单的“在线查询”重新查询，并优先显示在线结果。

数据来自 ip2region（Apache-2.0 或 MIT 许可）。ip-api.com 的免费服务不加密（HTTP），仅限非商业用途。

### 路由追踪

连接右键菜单的“路由追踪”，或工具栏的路由按钮（输入地址或主机名），在表格下方的标签里追踪从服务器出发的路由，标签名形如“路由 8.8.8.8”：跳数、IP、延迟（有回应的探测的平均值）、归属地、ASN 和主机名。

- 标签通过 exec 通道在服务器上运行 `nexttrace --json -M <目标>`：[NextTrace](https://github.com/nxtrace/NTrace-core) 作为独立程序运行，用它自己的服务定位每一跳，这正是它的用途；`-M` 让它不为地图上传路由。程序自己从不调用 NextTrace 的服务。NextTrace 结束时才输出 JSON，所以结束时才显示各跳。
- 服务器的 PATH（加上 `/usr/local/bin`、`/usr/sbin` 和 `/sbin`）里没有 `nexttrace` 时，标签会说明，并给出 NextTrace README 里的安装命令 `curl -sL https://nxtrace.org/nt | bash` 和复制按钮：程序从不在服务器上安装任何东西。服务器有 `traceroute -n -w 2` 或 `tracepath -n` 时改用它们追踪，各跳随到随显示，下载了 ip2region 数据时用它显示归属地；两个都没有时会说明。
- 很多服务器上 NextTrace 和 traceroute 需要 root 或发送原始数据包的权限：它们的报错显示在标签里。
- 标签上的按钮把路由复制成文本，或重新追踪。

- 更新：当前版本、“检查更新…”、“自动检查更新”（默认开）和检查到的新版本，或者这个副本为什么不能自行更新；见[更新](#更新)。

### 终端

“终端”页是字符编码和按键序列的全局默认值，连接编辑器里选“默认”的主机用它们。

- 字符编码：UTF-8（默认）、GBK、GB18030、Big5、Shift_JIS、EUC-JP、EUC-KR、ISO-8859-1 或 Windows-1252。要和服务器的 locale 一样：老的中文服务器 locale 是 GBK 的，选 UTF-8 时中文是乱码。
  - libghostty-vt 只解码 UTF-8，所以程序在 SSH 和终端之间转码（`internal/termenc`，用 `golang.org/x/text`）。服务器的输出解码成 UTF-8 再给终端，一个字被拆在两个包里也能拼回来，解不了的字节显示成 U+FFFD。键盘输入、粘贴和终端的回复编码后再发给服务器，这个编码里没有的字发成 `?`（不用 x/text 默认的 0x1A，那在 shell 里是 Ctrl+Z）。选 UTF-8 时不转码。
  - 文件面板的文件名和内置编辑器还是按 UTF-8 处理，服务器监控只读 ASCII 输出，所以都不受影响。
  - 在 `settings.json` 里是 `termEncoding`、`hosts.json` 里是 `encoding`，值是 `utf-8`、`gbk`、`gb18030`、`big5`、`shift_jis`、`euc-jp`、`euc-kr`、`iso-8859-1`、`windows-1252`。不认识的按 UTF-8。
- 退格键发送：`^?`（ASCII DEL，默认）或 `^H`（Control-H，一些老系统和串口控制台要这个）。连接时把服务器终端的 erase 字符设成一样的。Alt+退格键发送 Esc 加同一个字符。FinalShell 的第三项“VT220 - Delete”（`ESC [3~`）在 shell 里是向后删除，所以没有加。
- 删除键发送：`ESC [3~`（VT220，默认）、`^?` 或 `^H`。只换掉不带修饰键的 Delete；Ctrl+Delete 等仍然发送插件的 `ESC [3;5~`，程序按带修饰键的 Delete 读它。
- 改了在下次连接时生效（转码和 erase 字符都是连接时定的）。这一页有“恢复默认”。在 `settings.json` 里是 `termBackspace`（`ctrl-h`；没有是 `^?`）和 `termDelete`（`del`、`ctrl-h`；没有是 `ESC [3~`）。不认识的值按默认处理。

### 终端 › 鼠标

用的都是 terminal 插件本身的功能。

- 选中即复制（默认关）：用鼠标选中文字（还有“全选”）后自动复制到剪贴板。
- 右键：显示右键菜单（默认）、粘贴、复制选中的文字、有选中的文字时复制，没有时粘贴，或不做任何操作。服务器上的程序接管鼠标时（比如开了 `mouse=a` 的 vim）右键交给程序，按住 Shift 才按这里的设置。
- Ctrl+单击打开链接（macOS 是 Cmd+单击，默认开）：终端里显示的网址和 OSC 8 超链接用系统浏览器打开。关掉后单击链接什么也不做。插件没有关掉链接识别的开关，所以按住 Ctrl 时链接仍然显示下划线（文件路径也会显示），只是不打开。
- 鼠标滚轮每格滚动行数（1 到 20，默认 3）：只管鼠标滚轮，不改触控板。Windows 上 3 对应系统鼠标设置里的“一次滚动的行数”，其他值按比例换算。

选中即复制和滚动行数在已打开的终端里立刻生效（插件有 `SetCopyOnSelect`、`SetScrollMultiplier`）。右键和链接插件只在创建终端时读取，没有 setter，所以已打开的会话重新连接后才生效。重建正在用的终端会丢掉屏幕和滚动历史，所以不这么做。

在 `settings.json` 里是 `copyOnSelect`、`rightClick`（`paste`、`copy`、`copy-or-paste` 或 `ignore`；没有或不认识的值是右键菜单）、`noLinkClick` 和 `wheelLines`（没有是 3，超过 20 按 20）。

没有中键粘贴。插件只把中键交给接管鼠标的程序，自己不处理，也不公开程序是否接管了鼠标；应用另外处理中键的话，这样的程序会同时收到中键和粘贴的文字。插件也没有 Linux 的 PRIMARY 选区。要做需要插件加一个像 `RightClick` 那样的中键选项。

### 终端 › 快捷键

表格列出每个操作、现在的快捷键和默认的快捷键（见[快捷键](#快捷键)）。选中一行点 “修改…”，在弹出的框里按下新的组合键，点“确定”保存。“使用默认”填回默认键，“恢复默认” 恢复选中的一行，“全部恢复默认”恢复所有。

shell 需要的键不让用，框里用红字说明原因：

- 不带修饰键（或只带 Shift）的键；
- 只带 Ctrl 的字母、数字、标点、空格和方向键等（Ctrl+C、Ctrl+R、Ctrl+W、Ctrl+←……）；
- 只带 Alt 的这些键（Alt+B、Alt+F 在 shell 里是 Meta，按词移动）；
- macOS 上只带 Option 的这些键（会输入字符）；
- Windows 上 Ctrl+Alt 加字母（就是 AltGr，很多键盘布局用它输入字符）；
- 系统占用的键（macOS 的 Cmd+Q、Cmd+H、Cmd+M、Cmd+Tab、Cmd+空格等，Windows 和 Linux 的 Alt+Tab、Alt+F4，Windows 上的 Win 键组合）。

例外：“切换到第 1–9 个标签”可以用 Alt 加数字（readline 的数字参数很少用，GNOME Terminal 也这样），“终端：重新连接”可以用任何键（它只在会话断开、没有 shell 的时候起作用）。

和别的操作冲突时用黄字提示，“确定”后那个操作变成没有快捷键（显示“无”）。和终端自己的键（Ctrl+Shift+A 全选、Ctrl+= 缩放、Shift+PageUp 滚动、Ctrl+Insert / Shift+Insert 复制粘贴）冲突时也提示，“确定”后归这个快捷键。

窗口的快捷键立刻生效。终端的复制、粘贴是 terminal 插件的 `Keybinds`，插件只在创建终端时读取，所以改了之后新连接（包括重新连接）的会话才生效。

macOS 上这一页还有“将 Option 用作 Alt（Meta）键”（默认关，插件的 `OptionAsAlt`）：开了之后 Option+B 发送 Esc b，而不是输入 ∫。同样对之后连接的会话生效。

在 `settings.json` 里只存改过的键：`"shortcuts": {"find": "Ctrl+Alt+F", "closeTab": "none"}`。键名是 `copy`、`paste`、`find`、`fullScreen`、`reconnect`、`previousTab`、`nextTab`、`closeTab`、`connectionManager`、`newTab`、`switchTab`（值像 `"Alt+1-9"`）和 `focusCommandBar`。`Super` 在 macOS 上是 Cmd，`none` 是没有快捷键。没有或读不出来的就是默认。Option 用作 Alt 是 `optionAsAlt`。

### 终端 › 命令输入框

“在终端下方显示命令输入框”下面的“按键”一节列出输入框的按键：回车、Tab、↑ 或 Alt+H、历史列表里的 ← →、Esc，以及“终端 › 快捷键”里当前绑定的“聚焦命令输入框”快捷键。输入框本身不显示按键说明。

[命令输入框](#命令输入框)的开关，默认都打开，改了立刻对所有会话生效：

| 选项 | 键 | |
|---|---|---|
| 在终端下方显示命令输入框 | `noCommandBar` | 关掉后所有会话都不显示输入框：没有弹出列表，不保存也不读取历史，也不为它打开 exec 通道。关着的时候其他开关不能改。 |
| 路径选择 | `noCommandBarPaths` | 在路径上，或在第一个词之后的词上按 Tab。 |
| 历史命令 | `noCommandBarHistory` | ↑、Alt+H 和“历史”按钮，关掉时按钮隐藏。关掉后也不再保存发送的命令。 |
| 命令补全 | `noCommandBarCommands` | 在第一个词上按 Tab；关掉后在那里按 Tab 打开路径选择。 |
| 读取服务器的 shell 历史 | `noServerHistory` | 在历史列表里加上 `~/.bash_history` 和 `~/.zsh_history`。 |

这些键都以“关掉”命名，所以 `true` 表示关。“清空所有主机的历史…”先询问，再删除程序保存的所有主机的历史（`history` 文件夹）；服务器自己的历史文件不会改动。

### 网络监控

[网络页](#网络页)的 IP 归属地和路由追踪的选项。说明都放在这里，网络页本身保持简洁。

| 选项 | 键 | |
|---|---|---|
| 显示 IP 归属地（下载 ip2region 数据，约 11 MB） | `geoLocations` | `"on"` 显示“归属地”列；打开时如果没有数据就下载。`"off"` 隐藏这一列，保留文件；“不再询问”也是它。用户回答提示条之前没有这个键。 |
| 包括 IPv6 地址（再下载约 37 MB） | `geoLocationsV6` | IPv6 数据的同样设置。 |
| 在线查询 IP 归属地（ip-api.com） | `geoOnline` | `true` 在线查询数据中没有城市或运营商的地址。默认关闭，只在显示归属地时可用。 |

页面显示下载的数据在磁盘上占多少空间，“删除已下载的位置数据”先询问，然后删除 `geo/`（数据和在线查询的缓存），并关闭归属地和在线查询。在线查询开关下面的说明写明地址会发给第三方，以及 ip-api.com 的免费服务不加密、仅限非商业用途。最后一节说明路由追踪在服务器上运行什么。这些键都不同步：同意下载、同意把服务器的对端地址发给某个服务，是每台电脑自己的决定。

### 同步

“选项 › 同步”通过你已有的存储，让多台电脑上的连接和设置保持一致。Finallyshell 不为它运行任何服务器；在选择服务之前它是关闭的：

| 服务 | 要填什么 | 个人免费使用 |
|---|---|---|
| GitHub Gist | 一个带 `gist` 权限的个人访问令牌（“在 GitHub 上创建令牌”会打开已勾好权限的页面）。Gist ID 可以留空：第一次同步会找你账号下含 `finallyshell-sync.json` 的 gist，找不到就新建一个私密 gist，并记下它的 ID。 | 任何 GitHub 账号。 |
| WebDAV | 文件夹地址、用户和密码（服务提供应用密码时用应用密码）。文件夹不存在会自动创建。 | 坚果云、Nextcloud、群晖、Box 等。 |
| S3 兼容存储 | 端点、区域（Cloudflare R2 填 `auto`；留空为 `us-east-1`）、存储桶、文件名（留空为 `finallyshell-sync.json`）、访问密钥 ID 和私有访问密钥。请求用路径风格，并用 AWS Signature Version 4 签名。 | Cloudflare R2 和 Backblaze B2 有免费额度；MinIO 可以自己部署。 |

服务上只放一个文件。内容离开电脑之前，用 AES-256-GCM 加密，密钥由 Argon2id（3 轮、64 MiB、4 路并行、随机盐）从**同步密码**派生；同步密码由你自己设定，每台电脑都要输入。服务只能看到这是一个加密的 Finallyshell 文件，以及密钥派生的参数；主机名、地址、电脑名都在密文里。同步密码无法找回。密码不对时，同步会提示，不会改动任何东西。

同步的内容：

- 文件夹和连接，包括已删除的（这样删除也能同步到其他电脑），但不包括每台主机上次连接的时间，所以每台电脑的最近连接列表各是各的。
- 换到另一台电脑也有意义的设置：界面语言、外观，“常规”“鼠标”“快捷键”“终端”页，字体、配色、背景图片的填充方式和不透明度，以及每个副本都有的文件图标主题（Material、Seti 或简洁）。面板大小、下载文件夹、背景图片文件本身，以及从 VSIX 安装的图标主题，都留在各自的电脑上。
- 勾选“包括已保存的密码”（默认不勾）时，还包括记住了密码的主机的密码和私钥口令。没勾的电脑会原样保留文件里已有的密码。私钥文件本身不同步，主机只保留私钥的路径。

每次同步做三方合并：本机的数据、文件里的数据，以及上次同步后两边共有的数据（存在 `sync-state.json` 里，仍是加密的）。每个文件夹、主机、设置和密码分别合并：只有一边改了的，保留改过的；一边删了、另一边没改的，删除；两边都改了的，保留本机的版本，状态栏会显示有几项。第一次同步到某个服务（或改了同步密码之后）不会删除任何东西，两边有的都保留。同步过程中如果另一台电脑写了文件，会重新读取再合并一次（WebDAV 和 S3 会发送 `If-Match`，支持它的服务器会拒绝过时的写入；gist 在写入前再检查一次）。同步要改动本机连接之前，会先把 `hosts.json` 复制成 `hosts.before-sync.json`。同步进行中本机做的改动，会合并到同步带回来的结果之上，下次再同步出去；这期间保存的密码会保留，不会被同步带回的密码覆盖。同步进行中改了服务或它的字段时，这次同步带回的结果会被丢弃。

“立即同步”马上同步。“自动同步”在启动时、本机改动一分钟后（每分钟检查一次），以及每 5、15（默认）、30 或 60 分钟同步一次，以拉取其他电脑的改动。出错后会等到下一个间隔再试。状态栏显示上次同步的时间和结果，或者失败的原因。

“用本机数据替换远端…”会先询问，然后不做合并，直接把本机数据用当前输入的同步密码加密后写入文件。可以用它从头开始，或者更换同步密码（输入新密码，替换，再到其他电脑上输入新密码）。没勾“包括已保存的密码”时，替换后的文件里没有密码。

同步密码和服务的令牌、密码或私有密钥存在系统凭据存储里（见[密码存在哪里](configuration.md#密码存在哪里)）；系统没有凭据存储时只留在内存里。其他字段在 `settings.json` 的 `sync` 键里（见[同步](configuration.md#同步)）。

暂不支持：Google Drive、OneDrive、用浏览器登录 GitHub 代替令牌，以及恢复文件的旧版本。

## 快捷键

默认快捷键和 FinalShell 一样，都可以在“终端 › 快捷键”页修改。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 终端：复制 | Cmd+C | Ctrl+Shift+C |
| 终端：粘贴 | Cmd+V | Ctrl+Shift+V |
| 终端：查找 | Cmd+F | Ctrl+Shift+F |
| 终端：全屏 | Cmd+Enter | Ctrl+Shift+Enter |
| 终端：重新连接（会话断开时，焦点在终端区域） | Enter | Enter |
| 上一个标签 | Cmd+[ | Ctrl+Shift+Tab |
| 下一个标签 | Cmd+] | Ctrl+Tab |
| 关闭标签 | Cmd+W | Ctrl+Shift+W |
| 连接管理器 | Cmd+O | Ctrl+Shift+O |
| 新标签页 | Cmd+T | Ctrl+Shift+T |
| 切换到第 1–9 个标签 | Cmd+1…9 | Alt+1…9 |
| 聚焦命令输入框（再按回到终端） | Cmd+Shift+L | Ctrl+Shift+L |

说明：

- 以前 Ctrl+Shift+T 打开连接管理器，现在和别的终端程序一样是新标签页；新标签页上就有最近的连接和“连接管理器”按钮。连接管理器改成 Ctrl+Shift+O。
- 关闭标签在 macOS 上是 Cmd+W，不是 FinalShell 的 Cmd+Q（那是退出）。为了让 Cmd+W 到达窗口，macOS 上的菜单栏去掉了 MyGo 默认的“文件”菜单（里面的“关闭窗口”占着 Cmd+W）。主窗口里 Cmd+W 关闭标签。子窗口（选项、连接编辑器）里 Cmd+W 关闭这个子窗口，和别的 Mac 程序一样（“关闭标签”改成别的键后，那个键也关闭子窗口），Esc 也照样关闭。Windows 和 Linux 上子窗口用 Esc 和系统的关闭按钮。文件编辑器例外：Cmd+W（Ctrl+W）关闭标签，Esc 不关闭窗口（见[编辑远程文件](#编辑远程文件)）。
- macOS 上切换标签只用 Cmd+数字：Option+数字会输入字符（¡、™、£……）。
- Windows 上 terminal 插件默认还把 Ctrl+C（有选中时复制）和 Ctrl+V（剪贴板有内容时粘贴）绑成复制粘贴。Finallyshell 去掉了这两个，和 Linux 一样留给 shell（中断、原样输入下一个键）。复制粘贴用 Ctrl+Shift+C / Ctrl+Shift+V，或 Ctrl+Insert / Shift+Insert。
- 聚焦命令输入框不用 Ctrl+Shift+K：Windows 上那是终端的清屏（和 Windows Terminal 一样）。FinalShell 单按 Ctrl 切换，会和 shell 用的每个 Ctrl 键冲突，所以没有照搬。关掉命令输入框后，这个键交给终端。
- 只带 Ctrl 的字母键（Ctrl+A……Ctrl+Z 等）都是 shell 的，在 Windows 和 Linux 上不当快捷键用。MyGo 的 legacy 键盘模式下 Ctrl+[、Ctrl+I、Ctrl+M 什么也不发送，是上游的问题（#21），这里没有绕开。

## 布局和分隔条

拖动窗口各区域之间的分隔条调整大小（获得焦点后也可以用方向键），双击分隔条恢复默认大小。每个区域有最小尺寸，不会被拖到看不见。大小保存在 `finallyshell/settings.json`，下次启动恢复。

## 语言

界面有英文和简体中文。默认跟随系统语言，在“选项”窗口的“常规”页切换（点左下“会话”标题旁的齿轮按钮打开），选择会保存。

## 更新

Finallyshell 从 GitHub 上的发布自行更新，用的是 MyGo 的签名更新和它的更新窗口（updater 插件，原生 UI）。

- 检查：启动 10 秒后，之后运行期间每天一次，读取最新发布的更新清单（`update-<平台>.json`，`github.com/TooonyChen/finallyshell/releases/latest/download/` 下的一个小文件，不走 GitHub API）。“选项 › 常规”里的“自动检查更新”可以关掉它，默认开。
- 有新版本时弹出窗口，提供“安装更新”“稍后提醒我”和“跳过这个版本”，还有一个复选框：以后不问，直接下载并安装更新。跳过的版本后台检查不再提示，再下一个版本会提示。
- 安装时显示下载进度：发布里有从当前版本出发的增量更新时只下载这个小文件，否则下载整个应用。用应用内置的公钥验证 Ed25519 签名，替换应用，然后提供“立即重新启动”；不重启的话，下次启动时运行新版本。
- “检查更新…”立刻检查，已是最新版本或检查出错时也会说明；跳过的版本也会提示。它在“选项 › 常规”、托盘图标的菜单里，macOS 上还在应用菜单里（Finallyshell › 检查更新…）。
- “选项 › 常规”还显示当前版本，检查到新版本后显示“新版本 x.y.z 已推出”。
- 更新窗口用应用当前显示的语言（“界面语言”选项），切换语言之后打开的窗口用新的语言。

哪些副本能自行更新：

| 系统 | 安装方式 | 能自行更新 |
|---|---|---|
| macOS | 放在 `/Applications` 或 `~/Applications` 里的应用 | 能 |
| Windows | 安装程序的当前用户安装，在 `%LOCALAPPDATA%\Programs`；便携版 zip，所在文件夹可写时 | 能 |
| Linux | 用 `install.sh` 装在 `~/.local` 的 `.tar.gz` | 能 |
| Linux | 装在 `/opt` 的 `.deb` | 不能：由软件包管理器更新 |
| 任意 | 开发版本（`go run`、`mygo dev`） | 不能 |

不能自行更新时，“选项 › 常规”说明原因，并给出[发布页面](https://github.com/TooonyChen/finallyshell/releases)的链接，不提供检查按钮；菜单里的“检查更新…”打开的窗口也会说明。

说明：

- 0.2.0 及更早的版本没有更新功能：带更新功能的第一个版本需要手动安装一次，之后的版本会自行更新。
- macOS 版是 ad hoc 签名的，每次编译的签名都不一样。更新之后，macOS 可能会再问一次是否允许 Finallyshell 使用它存在钥匙串里的密码，和手动安装新版本之后一样。这一点还没有在真的 Mac 上确认。
- 更新窗口显示新版本的更新说明，中英文都有，和它在 GitHub 上的发布页面一样（`CHANGELOG.md`）。
- 不支持预发布版本、macOS 公证、Windows 的 Authenticode 签名，也没有给 `.deb` 的 apt 软件源。

用户的选择（自动检查、不问直接安装、跳过的版本、上次检查的时间）保存在 `updater.json`，见 [configuration.md](configuration.md#updaterjson)。
